# Sólidos de revolución en 3D

Visor interactivo de los sólidos de revolución del libro *Cálculo Integral*.
Cada sólido se abre con `solido.html#N`, donde `N` es el número del problema;
`index.html` los reúne todos.

En el visor, el sólido se gira arrastrando con el ratón, se acerca con la rueda
y se desplaza con el botón derecho. Se puede mostrar u ocultar el corte de un
cuarto de vuelta, la malla, el plano XY y los ejes.

`datos.js` e `index.html` se generan a partir del libro; no se editan a mano.
